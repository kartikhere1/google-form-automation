Copy this code into your Google Apps Script editor, add your Spreadsheet ID, then run generateForm(). 


          
        


        

          

            

              
1

              

                
Upload your Excel to Google Drive

                
Go to drive.google.com → New → File upload. Then open it with Google Sheets. Copy the Spreadsheet ID from the URL.

              

            

            

              
2

              

                
Install clasp and push code

                
Run npm install then npm run login to authenticate. Then npm run push to upload the script.

              

            

            

              
3

              

                
Paste your Spreadsheet ID

                
In the generated code, replace YOUR_SPREADSHEET_ID_HERE with your actual Sheet ID.

              

            

            

              
4

              

                
Run generateForm()

                
Open Apps Script editor (npx clasp open), select generateForm, click ▶ Run. Grant permissions when prompted.

              

            

            

              
5

              

                
Get your form link

                
Check the Execution Log for your shareable form link. You'll also receive an email if you enabled notifications.
