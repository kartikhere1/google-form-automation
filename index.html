1

            

              
Upload your Excel to Google Drive

              
Go to drive.google.com → New → File upload. Open with Google Sheets. Copy the Spreadsheet ID from the URL bar.

            

          

          

            
2

            

              
Open Google Apps Script

              
Go to script.google.com → New project. Delete the default code. Paste the generated script.

            

          

          

            
3

            

              
Fill in your IDs

              
Replace PASTE_YOUR_GOOGLE_FORM_URL_HERE and PASTE_YOUR_SPREADSHEET_ID_HERE with your actual values.

            

          

          

            
4

            

              
Run importResponses()

              
Select importResponses from the dropdown, click ▶ Run. Accept permissions. Check the Execution log for results.

            

          

          

            
5

            

              
Verify in Google Forms

              
Open your Google Form → Responses tab. All rows from the Excel should now appear as submitted responses.

            

          

          

            
⚠️

            

              
If you get "Invalid response" errors

              
The answer value in your Excel must exactly match an option in the form (for multiple choice / dropdown questions). Check for typos or extra spaces.
